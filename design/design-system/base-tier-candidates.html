Base-tier design language — three candidates

Each candidate answers one question differently: what makes a component visible at all? That is the identity lever our tokens never specified. Every candidate is drawn using only what compose.foundation can draw — gradients, strokes, paths, transforms. No blur, no platform shadow. And every one is derived from just two host-supplied colours, ink and surface, at varying alpha — which is how we know it survives someone else's theme.

Read the GRAYSCALE column first. That is the brief's acceptance test: if a component is still recognisable with all colour removed, the language is real form. If it dissolves, it was decoration.

ADefined by EDGE

Nothing is filled. Every component is a single precise contour, and the contour is lit from above — brighter along the top, fading toward the bottom — which is the glass sheet's own lighting model with the fill removed. The family resemblance is structural, not decorative.

rest 1.25dp gradient contour, no fill  ·  pressed contour brightens + scale 0.978  ·  disabled contour alpha ×0.35

BDefined by RECESS

Components are carved into the surface rather than sitting on it. Lighting is inverted against the glass sheet — shadow along the top lip, light catching the bottom — because that is what a real machined recess does. Teenage Engineering, not Material.

rest inset gradient well + inverted lip  ·  pressed well deepens, label sinks 1dp  ·  disabled well flattens toward the surface

CDefined by LAYER

Every component is two planes — a face, and a base peeking out beneath it. Depth comes from honest offset geometry, never from a blurred shadow, so it renders identically on every target. Pressing drops the face onto its base, like a real key bottoming out.

rest face + 3dp offset base plane  ·  pressed face travels 3dp, meets base  ·  disabled offset collapses to 1dp

Live specimens. The first button in each panel is interactive — press and hold to feel the motion, which is the part a screenshot cannot carry. All three use the same 120 ms cubic-bezier(.2,0,0,1) already in TOKENS.md as motionFast, so you are comparing the idea, not the timing.

Shape. All specimens use a true superellipse (n=4.2), carried over from the earlier pass — it survived, the weak part was the absence of an idea beneath it. In Compose this is a custom Shape backed by a Path; it is not a rounded rectangle, and the difference is most visible at the corners of the cards.
